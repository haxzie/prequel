"Lifetime" and "one-time" are not the same promise. Screen Studio's version of it is that the licence you bought keeps working and the updates stop.

## What Screen Studio says

Its own FAQ answers a question about one-time licences bought in the past. The licence is still valid. If your access to the latest updates and features has expired, you can renew it at any time. Purchasing one-time licences is no longer possible for new customers.

That is the whole statement. It does not say what renewing costs, or how long a payment keeps updates coming.

## What is and is not documented

| Question                       | Answer                                                |
| ------------------------------ | ----------------------------------------------------- |
| Does the licence keep working? | Yes, Screen Studio says it is still valid.            |
| Do updates continue?           | Access to the latest updates and features can expire. |
| Can you renew?                 | Yes, at any time.                                     |
| What does renewing cost?       | Not on Screen Studio's site.                          |
| Can new customers buy one?     | No.                                                   |

If your updates have lapsed and you want to keep going on the old version, you can. If you want new features, you renew, or you subscribe at the prices in [Screen Studio without a subscription](/articles/screen-studio-without-subscription). If you want out, [how to cancel Screen Studio](/articles/how-to-cancel-screen-studio) covers what a lapse means.

## What "buy once" can mean

Read the terms, not the label. A licence can mean the app forever with updates included, the app forever with updates for a period, or a fixed version. Ask three questions before you buy: does it renew, what happens to updates, and does the price you see now change.

[Screen Charm's one-time price](/articles/screencharm-subscription-refund) is $79 with free lifetime updates, according to its own page. And [Screen Studio zooms too much](/articles/screen-studio-zoom-too-much) is the page for what the app does while you are deciding.
