## Start and stop

**Shift + Command + R** starts a recording, and stops the one already running. It works while any application is focused.

You can change it in **Settings** under **Shortcuts**. Click the field, press the keys you want, and the new chord takes effect straight away.

- The chord has to include at least one of Command, Control or Option. A bare letter would fire while you type.
- If macOS or another app already holds the chord, Prequel says **That shortcut is not available** and keeps the old one working.

## Pause and resume

**Shift + Command + P** pauses the take and resumes it. Paused time is removed from the recording, so the finished video runs straight through. This chord is fixed.

The dock's pause button and the menu bar's **Pause** item do the same thing.

## Countdown

By default a three second countdown runs over the chosen region before recording begins, so you have time to move the pointer and settle. **Countdown before recording** in Settings offers **Off**, **3s**, **5s** and **10s**.

Press **Esc** during the countdown to cancel.
