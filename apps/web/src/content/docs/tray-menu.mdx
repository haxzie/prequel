## Click

A left click opens or closes the recording dock.

While recording, the icon is replaced by the elapsed time, so you can hide the dock and still see how long the take has been running.

## Right-click

The menu has everything the app can do without opening a window.

| Item | What it does |
| --- | --- |
| **Start Recording…** | Opens the dock. While recording this reads **Stop Recording**. The shortcut beside it is the one set in Settings. |
| **Record Entire Screen**, **Record a Window**, **Record an Area** | Go straight to that mode's overlay. |
| **Pause** or **Resume** | Only while recording. |
| **Open Recordings** | Opens the app window on your library of recordings. |
| **Open Recent** | The last ten recordings, each opening in the editor. |
| **Show Recordings in Finder** | Opens the recordings folder. See [Where files live](/docs/where-files-live). |
| **Open Shared Library** | Opens your shared recordings on prequel.sh in the browser. Shown when you are signed in. |
| **Show Log in Finder** | Reveals the app's log file, for [Troubleshooting](/docs/troubleshooting). |
| **Sign In…** | Shown when you are signed out. Opens the browser. |
| **Check for Updates…** | Reads **Update to…**, **Downloading…** or **Restart to Update** as an update moves along. |
| **Settings…** | Opens the app window on Settings. |
| **Quit Prequel** | The only way to quit, since there is no Dock icon. |
