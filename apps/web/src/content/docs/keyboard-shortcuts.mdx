## Anywhere

These work while any application is focused.

| Keys                | Does                                                                |
| ------------------- | ------------------------------------------------------------------- |
| Shift + Command + R | Start a recording, or stop the one running. Changeable in Settings. |
| Shift + Command + P | Pause or resume the recording.                                      |

## The teleprompter

While the island is showing, whatever application is in front.

| Keys                     | Does              |
| ------------------------ | ----------------- |
| Control + Option + Down  | On a sentence.    |
| Control + Option + Up    | Back a sentence.  |
| Control + Option + Space | Pause and resume. |
| Control + Option + 0     | Back to the top.  |

## The overlay

| Keys | Does                                               |
| ---- | -------------------------------------------------- |
| Esc  | Cancel choosing a source, or cancel the countdown. |

## The editor

Ignored while you are typing in a field.

| Keys                       | Does                                                       |
| -------------------------- | ---------------------------------------------------------- |
| Space                      | Play or pause.                                             |
| S                          | Split the clip at the playhead.                            |
| Z                          | Add a zoom at the playhead.                                |
| Backspace or Delete        | Delete the selected zoom or clip.                          |
| Command + Z                | Undo.                                                      |
| Command + scroll, or pinch | Zoom the timeline.                                         |
| Esc                        | Clear the selection in the composition, or close a dialog. |
| Option while dragging      | Pan the picture inside its box instead of moving the box.  |
| Shift while resizing       | Keep the proportions.                                      |

## The caption editor

| Keys                          | Does                                 |
| ----------------------------- | ------------------------------------ |
| Backspace over selected words | Cut that footage from the recording. |
| Command + Z                   | Undo.                                |
| Esc                           | Leave the text.                      |
